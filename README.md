# fs150_description

Visual-only ROS description assets for the current XGC2 FS150 RViz model.

The current Gazebo/PX4 SITL vehicle is still an FS150-on-iris injection owned by
`gazebo_sim_fs150_sitl`. This package intentionally contains only reusable RViz
assets: the iris-derived body mesh, clockwise/counter-clockwise propeller
meshes, and a lightweight visual URDF.
